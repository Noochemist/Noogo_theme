Project goals

Build a simple, maintainable, out-of-the-box Hugo theme:

  • Switch among five social-platform styles (xhs / zhihu / wechat / medium / quora)
  • Multilingual (zh-hans primary / en secondary)
  • Built-in site search, dark mode, responsive layout
