# HugMedia Theme Development

This is a **project page** example, used to test a top-level section (besides posts) and to demonstrate SEO-related front matter (`description` / `keywords`).

## Project goals

Build a simple, maintainable, out-of-the-box Hugo theme:

- Switch among five social-platform styles (xhs / zhihu / wechat / medium / quora)
- Multilingual (zh-hans primary / en secondary)
- Built-in site search, dark mode, responsive layout

## Tech choices

1. Template dispatch: `define` + `template`
2. Build: Hugo `css.Build` + `js.Build`
3. Math: KaTeX; diagrams: Mermaid
