Welcome to the multilingual example site of the **HugMedia** theme.

This site is used for content-rendering tests during development, covering:

- Math (KaTeX): triple integral derivation
- Flowchart (Mermaid)
- Image rendering (render-image)
- Code blocks (render-codeblock: language label + copy button)
- Blockquotes, lists, tables, links
