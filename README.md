# Hugo 主题集 / A Collection of Hugo Themes

---

## 简介 / Introduction

> 本仓库是一个持续扩充的 Hugo 主题集合。每个主题作为仓库中的一个独立目录，拥有自己独立的功能、风格与文档，并在其子目录 README 中说明特性与配置方法。各主题之间彼此解耦，可单独作为子模块(submodule)引入任意 Hugo 项目。

> This repository is a growing collection of Hugo themes. Each theme lives in its own directory with independent features, styles and documentation, and describes its features and configuration in its own README. The themes are decoupled from one another, so any of them can be pulled into any Hugo project as a git submodule.

### HugMedia

> HugMedia 是"词语 HugMedia = Hugo + social media"的合成词。它是一套以「社交平台视觉」为核心的 Hugo 主题：开箱即用中英多语言、共享悬浮导航特性、字体/菜单/作者等完整配置面，并提供 `xhs`(小红书)、`zhihu`(知乎)、`wechat`(公众号)、`medium`、`quora` 五种社交风格，切换仅需改动一个参数。

> HugMedia blends *Hugo* + *social media*. It is a Hugo theme centred on "social-platform visual languages", shipping multilingual (zh + en) support, a shared floating-navigation feature, and a complete configuration surface for fonts / menus / author, plus five switchable platform styles: `xhs`, `zhihu`, `wechat`, `medium` and `quora` — toggling a style is a one-parameter change.

## 未来规划 / Roadmap

> 本集合未来将围绕「不同风格 + 不同功能」两个维度持续扩充更多主题，例如面向文档站、杂志排版、极简博客等不同形态的主题。每个新主题会遵循与现有主题一致的结构与文档规范，并在此列表条目中同步更新简介与链接。

> The collection will keep growing along two axes — *styles* and *features* — adding more themes for use cases such as documentation sites, magazine layouts, minimalist blogs, and more. Every new theme will follow the same structure and documentation conventions, and this listing will be updated with its synopsis and link.

## 贡献指南 / Contributing

> 我们欢迎任何形式的内容——提出问题 (Issues)、报告缺陷、提交改进的拉取请求 (Pull Requests)。在提交 PR 前，请先阅读对应主题的 README，遵循其既有结构、配置与代码风格，并确保本地构建通过。所有讨论与代码注释优先使用中文，必要时可中英对照，以保持仓库语言习惯的一致性。请勿在提交内容中包含任何密钥或敏感信息。

> All kinds of contributions are welcome — opening issues, reporting bugs, and submitting pull requests. Before opening a PR, please read the relevant theme's README, follow its existing structure, configuration and code style, and make sure the site builds locally. Discussions and code comments prefer Chinese, and may be written bilingually where helpful to keep the repo's language conventions consistent. Never commit secrets or sensitive information.
