In the year 1878 I took my degree of Doctor of Medicine of the University of London, and proceeded to Netley to go through the course prescribed for surgeons in the army.

——这是华生医生回忆与福尔摩斯相遇前的开篇。

当初我以为他不过是位化学研究者；后来才知道，他在侦探艺术上的造诣，远超常人之想象：

《岳阳楼记》节选（《古文观止》）

第一段 · 叙事

庆历四年春，滕子京谪守巴陵郡。越明年，政通人和，百废俱兴，乃重修岳阳楼，增其旧制，刻唐贤今人诗赋于其上。属予作文以记之。

第二段 · 写景

予观夫巴陵胜状，在洞庭一湖：

  1. 衔远山，吞长江，浩浩汤汤，横无际涯；
  2. 朝晖夕阴，气象万千，此则岳阳楼之大观也。

至若春和景明，波澜不惊，上下天光，一碧万顷。——这既是写景，也是作者心境的映照。

代码优化示范与阅读计时

代码优化示范与阅读计时

本页用于演示代码块（语法高亮 + 语言标签 + 复制按钮）与阅读时间/字数统计相关的较长正文。它也演示了"优化前后"对比这一常见写法。

场景：求和优化

一段简单的 Python 实现非常直观，但可读性与边界处理可以更好。

优化前（朴素逐项累加）：

def sum_before(n):
    total = 0
    for i in range(1, n + 1):
        total += i
    return total

优化后（高斯公式 O(1)，并做入参校验）：

def sum_after(n: int) -> int:
    """返回 1 + 2 + ... + n，O(1)。"""
    if n < 0:
        raise ValueError("n must be non-negative")
    return n * (n + 1) // 2

其中行内代码如 O(1)、函数名 sum_after 均会以等宽字体呈现。

说明

  1. 前一段 sum_before 是教学用朴素版本；
  2. 后一段 sum_after 用公式直接求解，属代码优化常见示范；
  3. 两段代码都应有语言标签（python）与右上角复制按钮。

一段较长的正文（用于阅读计时/字数统计的占位）

你可能会好奇，为什么在同一篇文章里既保留朴素版又保留优化版。事实上，这在工程写作里非常常见：先给出"道理最直白"的版本让读者理解语义，再给出"性能最优"的版本让人在实践中使用。阅读器会据此统计字数与预计阅读时长，并在文章头部展示。若正文足够长，社交风格（如小红书、知乎）的卡片摘要也会据此截断到有限行数。

这段文字连同前面的标题、列表、表格与两段代码，共同构成了一个用于测试阅读时间/字数统计、以及 TOC 目录生成的多层级页面。每增加一个三级标题，右侧（或顶部）目录就会多一个锚点项，滚动时可高亮定位。

三重积分：球坐标法推导球体体积

三重积分：球坐标法推导球体体积

本页演示数学公式（KaTeX：行内与块级）如何在示例内容中呈现。

问题设定与变量代换

设球体 $B = { (x,y,z) : x^2 + y^2 + z^2 \le R^2 }$。改用球坐标：

$$ x = \rho\sin\varphi\cos\theta,\quad y = \rho\sin\varphi\sin\theta,\quad z = \rho\cos\varphi $$

其中 $\rho \in [0, R]$、$\varphi \in [0, \pi]$、$\theta \in [0, 2\pi]$，雅可比行列式为 $\rho^2\sin\varphi$。

该球体的体积可由「对 1 作三重积分」求得：

$$ V = \iiint_{B} 1,dV = \int_0^{2\pi}\int_0^{\pi}\int_0^{R}\rho^2\sin\varphi, d\rho,d\varphi,d\theta $$

逐层分离（可分离变量）

由于被积函数可分离，三重积分化为三个一重积分之积：

$$ \begin{aligned} V &= \left(\int_0^{2\pi} d\theta\right) \left(\int_0^{\pi}\sin\varphi, d\varphi\right) \left(\int_0^{R}\rho^2, d\rho\right)\ &= (2\pi)(2)\left(\frac{R^3}{3}\right) = \frac{4}{3}\pi R^3 \end{aligned} $$
